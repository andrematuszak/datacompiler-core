# Polices embarquées

Polices de substitution utilisées par les moteurs de rendu (`rebuilt_pdf`, `faithful_pdf`).
Seuls les fichiers `.ttf` sont inclus dans le package (voir `pyproject.toml`).

| Police | Utilisation | Licence |
|---|---|---|
| Liberation Sans (Regular, Bold, Italic, BoldItalic) | police principale | SIL Open Font License 1.1 — http://scripts.sil.org/OFL |
| DejaVu (Sans, Serif, Mono, Condensed, MathTeXGyre) | police de repli (`DejaVuSans.ttf`) | Licence Bitstream Vera / DejaVu (modifications DejaVu dans le domaine public) — http://dejavu-fonts.org/wiki/License |

Les licences ci-dessus sont celles indiquées dans les métadonnées des fichiers de police.
Si vous ajoutez une police, ajoutez-la dans ce tableau avec sa licence.
